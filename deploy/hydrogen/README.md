# Local Hydrogen container candidate

This Compose project is for local validation. It does not replace the separate live static frontend. Build and runtime credentials are separated: `scripts/prepare-hydrogen-context.mjs` copies only tracked storefront source and explicitly listed manifests/configuration into an ignored build context. It excludes `.env` files, project private files, tests and generated output. Compose reads an ignored runtime environment file when starting the container. The official Node image is selected by a verified digest in the private Compose environment.

Copy `.env.example` to ignored `.env`, then verify the image digest, chosen loopback port, and private `HYDROGEN_RUNTIME_ENV_FILE`. The runtime file must set the canonical origin for that port, Shopify development-store values, and `CUSTOMER_ACCOUNT_ENABLED=false` until an HTTPS callback is configured. `NODE_ENV`, listener host and listener port are set by Compose. Run `node scripts/prepare-hydrogen-context.mjs`, inspect the generated context, then `docker compose --env-file deploy/hydrogen/.env -f deploy/hydrogen/compose.yaml config --quiet` before building. Build and start only this Compose project. The Node adapter serves `/readyz` for health and uses its existing bounded request/cache settings. It serves the content-versioned Pulse GLB from its precompressed sidecar only for requests accepting gzip; the original GLB remains available and HTML/cart/account cache controls stay separate.

Before any remote staging proposal, capture read-only live files and resource inventory, verify no drift, record the built artifact digest, Caddy/DNS diff, private runtime environment plan, cost check and rollback. Obtain the concrete release authorization required by the master plan before changing the VPS or DNS.

The staging Caddy template uses `HYDROGEN_HOSTNAME` and `HYDROGEN_BIND_PORT` from the same private release environment. It adds `X-Robots-Tag: noindex, nofollow` and proxies only to the loopback listener. Render and validate the site locally before adding a separate site file to the shared Caddy import directory; never replace the live static site's file.

# Production applicability register

Updated: 2026-09-21
Status: planning register; controls and evidence are not yet implemented or legally reviewed.

This storefront is a **client-facing portfolio demo** with a realistic visual design and genuine sandbox flows. It does not represent an operating merchant, an available product, a clinical service, or an offer for sale. Catalog, order, review and test-account fixtures should be synthetic. The demo must not accept real payments. A convincing interface does not make demo claims true or establish legal compliance. Visitor inputs and existing quiz fields still require inspection; calling the project a demo does not make answers fictional or remove data duties.

This is an engineering applicability register, not legal advice, a policy pack, or a compliance certificate. Any real-sales launch requires a fresh assessment using the actual seller, products, claims, customer locations, data, vendors, transfers, payment setup, and operating practices. Applicable unresolved rows block real sales. Sources below are primary/official where available and were checked 2026-09-21; owners must recheck current text at each real-sales review.

## Release interpretation

“Demo ready” means the visible sample-data disclosures and sandbox boundaries are implemented and tested. It does not mean legal review is complete or that data obligations are avoided. “Real-sales ready” requires every applicable row to have a resolved applicability decision, named accountable owner, current source, qualified specialist review where needed, and implementation evidence. Rows may be non-applicable only with a written factual rationale; unknown is not equivalent to not applicable.

No legal certification is claimed by this document, the demo, an accessibility scan, a Shopify test order, or a security tool result. The current status is **planned register; implementation and merchant-specific applicability remain unverified**.
